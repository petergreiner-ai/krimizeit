KrimiZeit einrichten

Die Figuren sprechen über ElevenLabs. Dafür brauchst du ein eigenes ElevenLabs-Konto und einen API-Schlüssel. Die Gespräche laufen über dein Konto und werden dort abgerechnet.

1. Schlüssel anlegen

  1. Bei ElevenLabs anmelden, dann Developers → API Keys → Create API Key.
  2. Diese Rechte freigeben:
    • Text to Speech: Zugriff
    • ElevenLabs Agents: Schreiben (Write)
    • Voices: Lesen (Read)
  3. Den Schlüssel (beginnt mit sk_) unten einfügen.

2. Einrichten

Der Schlüssel wird nur in diesem Browser gespeichert (localStorage) und nur an api.elevenlabs.io geschickt. Die Einrichtung legt in deinem Konto einen Agenten „KrimiZeit“ mit drei Werkzeugen an. Ein zweiter Durchlauf verwendet diese wieder.

Fertig!
